    路程時間
    開啟前必須先做這兩件事，少一件就會回 403：
    ① Cloud Console →「API 和服務 → 程式庫」，搜尋 Routes API 並按啟用
    ② 憑證 → 編輯你的金鑰 →「API 限制」清單裡把 Routes API 也勾起來（原本只勾了 Places API）
    設定生效可能要等一兩分鐘。
    一次搜尋算「店家數」個元素（20 家 = 20 元素）。走路／腳踏車／開車屬 Essentials，每月 10,000 元素免費； 機車屬 Enterprise，每月只有 1,000 元素免費，大約 50 次搜尋就會用完。
    這個月已用 0 個元素。

    只有在你替 Routes API 另外開了一把金鑰時才需要填。留空的話路程時間會用上面那把。
    若你是在 Routes API 頁面按「建立憑證」拿到新金鑰，它預設完全沒有限制——請務必回去設定應用程式限制（你的網域）與 API 限制（只勾 Routes API），不限制的金鑰外流風險最高。
